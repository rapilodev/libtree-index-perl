zwei Klassen: Tree::Node und Tree (+ separate Tree::Node::Data)
Tree::Node::Data speichert nur rohe Knotendaten (Value + Links als Array)
Tree speichert alle Nodes in einem Array und vergibt IDs
Tree::Node ist nur ein Proxy (Tree + ID)
echte Struktur liegt im Tree + Data (Parent/Child/Sibling als IDs)
Nodes werden über IDs im Tree-Array referenziert
Traversierung arbeitet mit IDs, nicht mit echten Objektverknüpfungen
Trennung: Data (Inhalt) + Tree (Struktur) + Node (Handle/Wrapper)
